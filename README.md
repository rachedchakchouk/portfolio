# Portfolio v1 (archived)

First version of my personal portfolio: a multi-page static website (Home, About, Skills, Projects,
Contact) built with **HTML5, CSS3, Bootstrap and JavaScript**, with a PHP mail form (PHPMailer +
reCAPTCHA) and deployed on **Firebase Hosting** through a GitHub Actions workflow.

> ⚠️ This version is no longer maintained.
> 👉 Current portfolio: **[rached-chakchouk.netlify.app](https://rached-chakchouk.netlify.app)** —
> source code in [rached-chakchouk-portfolio](https://github.com/rachedchakchouk/rached-chakchouk-portfolio).

## Tech stack

- HTML5, CSS3, Bootstrap, JavaScript
- PHP contact form (PHPMailer, reCAPTCHA)
- Firebase Hosting + GitHub Actions (preview deployments on pull requests)

## Pages

| Page | File |
|---|---|
| Home | `index.html` |
| About | `about.html` |
| Skills | `skills.html` |
| Projects | `projects.html` |
| Contact | `contact.html` |

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
